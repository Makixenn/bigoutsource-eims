# Feature: Evaluations

The Evaluations feature tracks critical employee milestones (1st Month, 3rd Month, etc.) to ensure timely performance reviews.

## 1. Overview
The `Evaluations.tsx` page provides a visual dashboard and calendar-based list to track upcoming, due, and past-due evaluations. It operates on a specific subset of date fields on the `Employee` model.

## 2. Tracked Milestones
The system monitors five specific evaluation dates per employee:
- `1st Month`
- `3rd Month`
- `5th Month`
- `6th Month`
- `Anniversary`

## 3. Frontend Implementation (`Evaluations.tsx`)

### Key Features
1. **Analytics Dashboard**
   - Displays counts for evaluations **Due This Month**, **Due Next Month**, and **Due Today**.
   - Includes a 6-month forecast bar chart (powered by `recharts`) showing the upcoming pipeline of evaluations.

2. **Status Calculation**
   - Dates are evaluated relative to `today` at midnight to determine their exact status:
     - `Due Today` (0 days diff) - Highlighted in Red.
     - `Upcoming` (1-7 days away) - Highlighted in Orange.
     - `Past` (overdue, < 0 days diff) - Highlighted in Gray.
     - `Future` (> 7 days away) - Highlighted in Blue.

3. **Calendar View & Filtering**
   - By default, the table shows all employees who have *any* evaluation falling in the currently selected month and year.
   - Users can use the "Previous Month" and "Next Month" controls to paginate through time.
   - Search allows filtering by Employee Name or `DEPARTMENT/CAMPAIGN`.
   - A dropdown filter allows isolating specific statuses (e.g., showing only "Due Today" within the current month).

## 4. Backend Context (Reference)
The frontend relies heavily on data generated by the backend cron job (documented in `feature-scheduled-tasks.md`). While the frontend displays the dates and calculates real-time "due today" badges, the backend cron job is responsible for actually sending the email alerts based on those same dates.
